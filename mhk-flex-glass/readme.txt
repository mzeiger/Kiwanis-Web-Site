Gutenberg flex container with optional frosted glass effect.

== Description ==

Adds a "Flex Glass" block under Design in the block inserter.

* Flex column or row
* Alignment, gap, padding, max width
* Optional frosted glass (backdrop blur)
* Styles ship in a real CSS file so layout works when post content is shown through Oxygen

== Installation ==

1. Copy the `mhk-flex-glass` folder into `wp-content/plugins/`
2. Activate **MHK Flex Glass** in Plugins
3. In a post, Add block → search **Flex Glass**
4. Add Image, Paragraph, Custom HTML, etc. inside it

== Usage ==

Select the Flex Glass block and use the sidebar controls:

* Direction: Column or Row
* Align / Justify
* Gap, Padding, Max width (e.g. 318px or 100%)
* Frosted glass: on/off

Glass looks best over a colored or image background.
